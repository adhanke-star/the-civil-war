# The Civil War

A real-time Civil War battle game in the browser, in the spirit of *Ultimate General: Gettysburg*:
the battlefield looks like a painted period map, regiments move smoothly in formation, and the history
is cited.

**Play:** https://adhanke-star.github.io/the-civil-war/ (or on a Mac double-click `play.command`). Click a
blue brigade, drag from it to draw its march, and use Hold / Charge / Run / Fallback / Halt. The menu (☰)
has the controls and the Quality setting (G toggles Auto / High / Low).

**Status:** see `PLAN.md` (weekly playable milestones) and `STATE.md`.

Plain JavaScript ES modules, three.js 0.186.1, no build step. Third-party libraries are vendored in
`vendor/` with their licenses. Asset credits are in `ATTRIBUTION.md`.
